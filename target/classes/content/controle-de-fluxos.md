# Estruturas Condicionais em Java

Estruturas condicionais servem para tomar decisões no código. Analogia: Imagina que você está saindo de casa:

- Se estiver chovendo, você pega guarda-chuva
- Senão, sai normal

Isso é exatamente o que o Java faz com if/else. Você usa condicionais quando precisa que o programa escolha um caminho com base em uma condição verdadeira ou falsa.

## Principais estruturas:

- if
- if / else
- if / else if / else
- switch
- operador ternário
