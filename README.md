## 📖 Sobre

Este repositório reúne minhas soluções para os exercícios do livro **200 Exercícios Java: Domine Java através de exercícios e se prepare para o mercado de trabalho**, de **Matheus Battisti**.

O objetivo é fortalecer os fundamentos da linguagem Java por meio da prática diária, desenvolvendo lógica de programação, boas práticas e domínio dos principais conceitos da linguagem.

## 🎯 Objetivos

- Praticar Java diariamente
- Reforçar os fundamentos da linguagem
- Desenvolver raciocínio lógico
- Evoluir na resolução de problemas
- Criar o hábito de versionar código com Git e GitHub

## 📂 Estrutura do projeto

```text
src
├── capitulo01
├── capitulo02
├── capitulo03
└── ...
```

Cada exercício possui uma classe própria com um nome descritivo, facilitando revisões futuras.

Exemplos:

- `HelloWorld.java`
- `TiposDeDados.java`
- `ConversaoDeTipos.java`
- `OperacoesAritmeticas.java`

## 🛠 Tecnologias

- Java 21
- IntelliJ IDEA
- Git
- GitHub
